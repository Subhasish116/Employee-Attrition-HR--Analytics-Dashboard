# HR Analytics Dashboard

## Project Overview

The HR Analytics Dashboard is an end-to-end data analytics project designed to provide meaningful insights into employee performance, workforce demographics, attrition trends, recruitment effectiveness, salary distribution, and employee satisfaction.

This project combines Python for data cleaning and exploratory data analysis (EDA) with Power BI for creating interactive dashboards that support data-driven HR decision-making.

---

## Objectives

* Analyze employee demographics and workforce composition.
* Monitor employee attrition and retention.
* Evaluate recruitment sources and hiring effectiveness.
* Compare salary distribution across departments.
* Measure employee satisfaction and performance.
* Track employee tenure and absenteeism.
* Provide actionable business insights for HR management.
